# NEXORA Ecommerce Website

A responsive multi-page ecommerce website built with HTML, CSS, and JavaScript.

## Features

- Product listings and product details
- Search, filtering, and sorting
- Shopping cart using localStorage
- Debit-card checkout demonstration
- Login and signup validation
- Dark and light mode
- Responsive design

## Live Website

https://dev11324.github.io/NEXORA/

> The checkout is for demonstration only and does not process real payments.
